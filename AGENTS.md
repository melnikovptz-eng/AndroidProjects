# Инструкции ИИ для ветки Aeroclub

Канонический общий реестр проектов находится в основной ветке репозитория:
- https://github.com/melnikovptz-eng/AndroidProjects/blob/main/AGENTS.md
- https://github.com/melnikovptz-eng/AndroidProjects/blob/main/PROJECT_REGISTRY.md
- https://github.com/melnikovptz-eng/AndroidProjects/blob/main/WORKLOG.md

Перед работой прочитать эти документы. Рабочая ветка Aeroclub Informer — aeroclub-informer, каталог — Aeroclub/. Не переключать проект на main ради разработки без явного основания.

Для APK обязательно проверить workflow run и source SHA. Последний успешный Aeroclub run #274 собран с SHA c573778f62c92a8c8187f0ab07d3885ee2a4a5ec, а известный HEAD ветки на момент реестра — 24b8630185caf41ebbe8143e10b525e435050721; это разные коммиты, поэтому этот APK не подтверждает текущую версию.

Обновлять общий WORKLOG после завершённого логического блока. Не выполнять полный повторный аудит, если HEAD не изменился и задача не затрагивает другие модули.
