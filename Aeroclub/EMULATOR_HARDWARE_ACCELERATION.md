# KD PILOT — обязательная политика запуска Android Emulator

ЭТОТ ФАЙЛ ОБЯЗАТЕЛЬНО ПРОЧИТАТЬ ПОЛНОСТЬЮ ПЕРЕД КАЖДЫМ ЗАПУСКОМ ЭМУЛЯТОРА.

## Непреложные требования
1. Аппаратная виртуализация CPU обязательна: Android Emulator запускается только с `-accel on` и доступным Linux KVM (`/dev/kvm`).
2. Аппаратный/host GPU rendering обязателен: запускать только с `-gpu host`. Запрещены `swiftshader`, `swiftshader_indirect`, `angle_indirect`, software rendering и автоматический откат на программный рендеринг.
3. Перед запуском проверять `emulator -accel-check`, наличие и доступность `/dev/kvm`.
4. После запуска сохранять диагностические сведения о фактическом GPU renderer из вывода эмулятора и Android SurfaceFlinger. Не считать наличие KVM доказательством аппаратного GPU rendering.
5. Если host GPU rendering недоступен, тест должен завершиться явной ошибкой. Не подменять аппаратное ускорение программной эмуляцией и не объявлять UI-тест успешным.
6. Каждый UI acceptance запуск обязан сохранять PNG screenshot каждого проверяемого экрана и диагностический XML/UI dump. При ошибке сохранять уже полученные скриншоты и лог ошибки.
7. Перед каждым новым запуском эмулятора CI должен повторно вывести/прочитать этот файл в логе job. Это обязательный preflight, не рекомендация.

## Канонические параметры
```text
-accel on
-gpu host
```

## Проверка результата
В логах должны отдельно присутствовать:
- KVM acceleration check: passed;
- emulator GPU mode: host;
- фактический renderer, полученный после старта.

Нельзя называть SwiftShader или llvmpipe аппаратным ускорением GPU.
