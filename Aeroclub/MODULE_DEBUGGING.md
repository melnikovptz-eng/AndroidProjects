# Отладка модулей Aeroclub

Ветка: `aeroclub-informer`. Изменения ограничены каталогом `Aeroclub/`.

## Локальный журнал

- `ModuleDebugLog` пишет JSONL в приватный файл приложения `module-debug.log`.
- При достижении 1 MiB активный файл переносится в `module-debug.log.1`; предыдущая резервная копия заменяется только после успешного удаления.
- Поля события: `time`, `module`, `action`, `outcome`, `detail`, `thread`; для измеряемых операций добавляется `duration_ms`.
- Длительность измеряется монотонными часами через `DebugOperation`.
- В журнал нельзя писать токены, пароли, полные тексты сообщений и ненужные персональные данные.
- Просмотр последних событий доступен в разделе «Уведомления» панели администратора.

## Экспорт

Кнопка «Поделиться журналом отладки» открывает системное меню передачи полного доступного журнала (резервная копия + активный файл). Это только передача выбранному пользователем приложению: приложение не утверждает, что журнал загружен или доставлен.

Прямая загрузка в GitHub из APK отключена. Любой токен, встроенный в APK, можно извлечь; это противоречит требованиям безопасности проекта. Текущий режим приложения — локальный, без серверного посредника, поэтому безопасная автоматическая отправка в GitHub пока заблокирована. Секреты сборки больше не передаются в Gradle и не включаются в APK.

## Не подтверждено

- Полнота событий по всем операциям ещё требует поэтапной проверки.
- Не проверены ротация на реальном устройстве и передача очень большого журнала разным приложениям.
- До теста на устройстве нельзя утверждать, что экспорт работает на конкретной прошивке.

## Сценарии приёмки

1. Выполнить несколько действий в информере и админ-панели; проверить безопасные события.
2. Проверить, что время операции записывается в `duration_ms`.
3. Довести журнал до ротации и убедиться, что активный и резервный файлы читаются в правильном порядке.
4. Нажать «Поделиться журналом отладки», выбрать приложение-получатель и проверить содержимое.
5. Убедиться, что в APK нет GitHub-токена и приложение не запрашивает сетевые разрешения только ради диагностики.
