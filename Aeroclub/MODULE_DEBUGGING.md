# Отладка модулей Aeroclub

Ветка: `aeroclub-informer`. Изменения ограничены каталогом `Aeroclub/`.

## Единые правила журналов

- Основной читаемый файл: `Download/Aeroclub_Informer_debug.log` (понятное имя проекта + назначение).
- Журнал записывается в Downloads через Android MediaStore на Android 10+; для более старых Android требуется доступ к публичному каталогу Downloads.
- Максимум файла — 80 000 символов. При достижении лимита старое содержимое заменяется новым журналом; файл не должен разрастаться бесконечно.
- Внутренняя копия приложения используется для восстановления, если публичный файл временно недоступен.
- Файл предназначен для прикрепления к сообщению ChatGPT. Лимит 80 000 символов — консервативный предел проекта, поскольку точный лимит сообщения может меняться.
- Общие правила для всех проектов находятся в корневом `GLOBAL_PROJECT_RULES.md`.

## Поля и безопасность

- Поля события: `time`, `project`, `module`, `action`, `outcome`, `detail`, `thread`; для измеряемых операций добавляется `duration_ms`.
- Длительность измеряется монотонными часами через `DebugOperation`.
- В журнал нельзя писать токены, пароли, полные тексты сообщений и ненужные персональные данные.
- Просмотр последних событий доступен в разделе «Уведомления» панели администратора.

## Экспорт

Кнопка «Поделиться журналом отладки» передаёт ограниченный журнал из Downloads через системное меню. Это только передача выбранному пользователем приложению: приложение не утверждает, что журнал загружен или доставлен в GitHub.

Прямая загрузка в GitHub из APK отключена. Любой токен, встроенный в APK, можно извлечь; безопасная автоматическая отправка в GitHub требует доверенного серверного посредника. В текущем локальном режиме сервер не подключён.

## Не подтверждено

- Запись в публичный Downloads и ротация ещё не проверены на реальном TECNO/Android-устройстве; CI не заменяет тест телефона.
- Полнота событий по всем операциям требует отдельной проверки.

## Сценарии приёмки

1. Выполнить действия в информере и админ-панели; проверить, что файл появляется в Downloads с именем `Aeroclub_Informer_debug.log`.
2. Убедиться, что файл не превышает 80 000 символов и после ротации содержит последние события.
3. Нажать «Поделиться журналом отладки», выбрать приложение-получатель и проверить содержимое.
4. Убедиться, что в APK нет GitHub-токена и сетевые разрешения не добавлены только ради диагностики.
