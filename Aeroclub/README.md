# Аэроклуб — информер Android

Отдельный Android-проект для информера ближайшего вылета. Макет выдержан в светлой карточке со скруглёнными углами и стандартными Android-кнопками. Приложение-превью и виджет используют одинаковую структуру: название полёта, дата/время, место встречи, статус и четыре действия в сетке 2×2.

## Сборка
- Android Gradle Plugin 8.6.1
- Gradle 8.7
- JDK 17
- compileSdk 35
- APK собирается GitHub Actions в отдельной ветке `aeroclub-informer`.

## Реализовано
- Настоящий Android Home Screen Widget.
- Превью с той же компоновкой, что и виджет.
- Локальное сохранение ответа «Я еду» / «Я не еду» с привязкой к активному вылету и стабильному локальному ID устройства (до подключения авторизации).
- «Маршрут» открывает поиск места встречи в приложении карт.
- «Telegram» открывает системное меню отправки текста о ближайшем вылете.
- Локальная панель администратора: обзор, вылеты, участники, сообщения, календарь, настройки и состояние уведомлений.
- Администратор может создавать, редактировать, удалять и выбирать активный вылет из локального списка; изменения обновляют установленный виджет.
- Для вылета можно хранить локальную отметку публикации/черновика; эта отметка не публикует данные на сервере.
- Локальный FlightRepository хранит несколько вылетов с устойчивыми ID, ISO-датой `yyyy-MM-dd` и мигрирует прежние поля SharedPreferences в первый вылет.
- Участники имеют стабильные локальные ID; доступны поиск, добавление, переименование, удаление и статусы по каждому вылету.
- Старые записи участников мигрируют из прежнего строкового формата.
- Ответы администраторского списка и ответы из информера проходят через AttendanceRepository.
- Для сообщений есть три шаблона, предпросмотр, сохранение черновиков и локальная история; открытие меню отправки не считается доставкой.
- Общие настройки клуба вынесены в ClubSettingsRepository.
- SyncRepository ведёт локальную очередь метаданных изменений и показывает, что сервер не настроен; сетевую синхронизацию не имитирует.
- Журнал последних 200 технических событий доступен из раздела уведомлений.
- Локальные напоминания ставятся за 1 час до будущего вылета через AlarmManager; расписание восстанавливается после перезагрузки. Push через FCM пока не подключён.

- Экспорт списка участников и статусов через системное меню «Поделиться».
- Календарь выводит сохранённые вылеты по полной ISO-дате, не смешивая одинаковые числа разных лет.
- Сводка участников считается по локальным записям, без фиктивных чисел и демонстрационных имён.
- Настройка места встречи по умолчанию отделена от места конкретного вылета.

## Важные ограничения прототипа
Название, дата, время и адрес по умолчанию демонстрационные. Маршрут ищется по текстовому адресу, а не по подтверждённым координатам. Ответы и добавленные участники хранятся только на этом устройстве. Ответы локального устройства привязаны к ID вылета и локальному ID участника; это не полноценная учётная запись, ответы не синхронизируются между устройствами. Список участников состоит из локально добавленных записей и не является общей базой клуба. Нет работающей серверной синхронизации (есть только локальная очередь), контактных полей, массовой отправки сообщений, авторизации администратора и FCM-push. Локальные напоминания зависят от разрешения Android и требуют проверки на реальном устройстве. Кнопка «Telegram» открывает системное меню отправки текста, а не гарантирует доставку в Telegram. Эти функции нельзя считать готовыми до подключения API клуба, безопасной авторизации и серверной инфраструктуры.
