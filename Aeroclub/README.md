# Аэроклуб — информер Android

Отдельный проект, не связанный исходниками с PMCA. Первый этап повторяет идею предоставленного макета: компактная карточка ближайшего полёта, дата/время, место встречи и кнопки «Я еду», «Я не еду», «Маршрут».

## Сборка
Проект использует Android Gradle Plugin 8.6.1, Gradle 8.7, JDK 17/21, compileSdk 35. Сборка APK запускается GitHub Actions.

## Сейчас реализовано
- Android-приложение-превью информера.
- Настоящий Android Home Screen Widget с кнопками подтверждения участия.
- Сохранение локального статуса участия между обновлениями виджета.
- Стандартная Android-компоновка, светлая карточка, адаптивная ширина виджета.

## Пока не подключено
Данные рейсов в этом прототипе демонстрационные. Сетевой сервер, роли администратора/участника, календарь, личные сообщения, маршруты и FCM-пуши будут отдельными следующими этапами. Кнопка маршрута пока не открывает навигацию.
