# Аэроклуб — информер Android

Отдельный Android-проект для информера ближайшего вылета. Макет выдержан в светлой карточке со скруглёнными углами и стандартными Android-кнопками. Приложение-превью и виджет используют одинаковую структуру: название полёта, дата/время, место встречи, статус и четыре действия в сетке 2×2.

## Сборка
- Android Gradle Plugin 8.6.1
- Gradle 8.7
- JDK 17
- compileSdk 35
- APK собирается GitHub Actions в отдельной ветке `aeroclub-informer`.

## Реализовано
- Настоящий Android Home Screen Widget.
- Превью с той же компоновкой, что и виджет.
- Локальное сохранение ответа «Я еду» / «Я не еду».
- «Маршрут» открывает поиск места встречи в приложении карт.
- «Telegram» открывает системное меню отправки текста о ближайшем вылете.
- Локальная панель администратора: обзор, вылеты, участники, сообщения, календарь, настройки и состояние уведомлений.
- Администратор может редактировать название, дату, время и место встречи; изменения обновляют установленный виджет.
- Управление статусами демонстрационных участников.
- Добавление собственных локальных записей участников.
- Экспорт списка участников и статусов через системное меню «Поделиться».
- Экран календаря с выбором даты и переходом к данным ближайшего вылета.

## Важные ограничения прототипа
Название, дата, время и адрес по умолчанию демонстрационные. Маршрут ищется по текстовому адресу, а не по подтверждённым координатам. Ответы и добавленные участники хранятся только на этом устройстве. Список содержит демонстрационные записи и не является реальным списком клуба. Нет общей серверной синхронизации, реальных контактов участников, отправки сообщений всем участникам, авторизации администратора и FCM-push. Кнопка «Telegram» открывает системное меню отправки текста, а не гарантирует доставку в Telegram. Эти функции нельзя считать готовыми до подключения API клуба, безопасной авторизации и серверной инфраструктуры.
