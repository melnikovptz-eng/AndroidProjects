### AERO-006 — Автоматический файл обмена данными о полётах в Downloads
- **Статус:** IN PROGRESS / BLOCKER
- Код: `FlightDownloadExchange` автоматически публикует `Download/Aeroclub_Informer_flights.json`, импортирует изменённый файл по SHA-256, проверяет схему и уникальность ID. Главный экран календаря/админ-панель опрашивают файл раз в 5 секунд в foreground.
- **Папка/имя:** Android `Download/Aeroclub_Informer_flights.json`.
- **Требование:** приложение само сохраняет актуальные данные о полётах в этот файл и само читает его для обновления календаря. Не требовать ручного экспорта/импорта в обычном потоке.
- **Работа:** определить единый JSON schema/version; атомарная/безопасная запись; чтение при запуске и возврате приложения; обработка изменения файла; защита от циклической перезаписи, дублей и повреждённых данных; согласовать, кто является источником истины, чтобы внешний файл и внутренний репозиторий не затирали изменения друг друга. На Android 10+ использовать MediaStore/SAF в соответствии с ограничениями Android; ошибки доступа явно отображать и журналировать.
- **Приёмка:** файл появляется в Downloads без ручного действия; содержит текущие вылеты; после изменения файла календарь отображает актуальные данные; после перезапуска данные не теряются; повторное чтение не создаёт дубли; отказ доступа не выдаётся за успех.
