# Эталон главного экрана «Аэроклуб»

Это постоянная точка входа для исходного дизайна и правил его реализации.

## Имена файлов

- `dezign.jpg` — существующий оригинальный макет, не изменять и не перезаписывать.
- `DESIGN_REFERENCE.md` — обязательные правила работы с эталоном.
- `HTML_RECONSTRUCTION_ALGORITHM.md` — пошаговый алгоритм реконструкции интерфейса в HTML: контейнеры, относительное позиционирование, разделители, измерения и сравнение с эталоном.
- `CSS_DESIGN_SPECIFICATION.md` — каталог CSS-правил и проверок, включая перекрывающиеся карточки, блок аватаров, индивидуальные радиусы углов, границы, геометрию, типографику и состояния элементов.
- `main-screen-specification.jpg` — предполагаемая спецификация главного экрана (размеры, цвета, типографика и компоненты); считать доступной только после фактического добавления файла.
- `main-screen-coordinate-layout.png` — предполагаемое изображение экрана с координатной сеткой; считать доступным только после фактического добавления файла.

## Порядок работы

1. Изучить неизменяемый оригинал.
2. Следовать `HTML_RECONSTRUCTION_ALGORITHM.md`.
3. Использовать `CSS_DESIGN_SPECIFICATION.md` как список проверок; значения не придумывать, а измерять по эталону.
4. Построить и проверить дерево контейнеров, затем зафиксировать измерения.
5. Создать HTML-макет и сравнить его с оригиналом.
6. Перед переносом в Android отдельно проверить визуальную точность и функциональность.

Оригинал и документацию хранить в `Aeroclub/design/` в ветке `aeroclub-informer`. Новые версии сохранять отдельными файлами; оригинал не перезаписывать. Не отмечать файлы как созданные, а проверки как выполненные, пока это не подтверждено фактически.
