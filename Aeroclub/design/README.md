# Эталон главного экрана «Аэроклуб»

Это постоянная точка входа для исходного дизайна и правил его реализации.

## Имена файлов

- `dezign.jpg` — существующий оригинальный макет, не изменять и не перезаписывать.
- `main-screen-specification.jpg` — полная спецификация главного экрана (размеры, цвета, типографика и компоненты).
- `main-screen-coordinate-layout.png` — изображение экрана с координатной сеткой для измерения и позиционирования.
- `DESIGN_REFERENCE.md` — обязательные правила работы с эталоном.

## Правило

Оригинал и спецификацию хранить в `Aeroclub/design/` в ветке `aeroclub-informer`. Не заменять оригинал новой версией. Новые версии сохранять отдельными файлами с датой/номером версии и явно отмечать актуальную. Перед изменением UI открыть эталон, а после изменения отдельно проверить внешний вид и работу элементов.

> Важно: названия двух изображений выше предназначены для новых вложений из текущего обсуждения. Не считать их загруженными, пока соответствующие файлы не появятся в GitHub.
