## Полный реестр стилей — обязательная калибровка

Для каждого визуального элемента фиксировать значение, единицу измерения, способ измерения и уверенность. Не подставлять значения «на глаз» как точные.

| Группа | Параметры, которые необходимо измерить |
|---|---|
| Масштаб | исходный размер, границы контента, масштаб предпросмотра, соотношение сторон |
| Компоновка | координаты и размеры контейнеров; display; flex/grid; направление; выравнивание; порядок; gap |
| Позиционирование | position; inset; z-index; контексты наложения; перекрытие аватара/карточек |
| Размеры | width/height; min/max; box-sizing; внутренние и внешние отступы |
| Фон | основной цвет; градиент; направление и точки градиента; прозрачность; фоновые изображения |
| Контуры | border-width; border-style; цвет; отдельные радиусы каждого угла |
| Тени | box-shadow: X/Y, blur, spread, цвет и альфа; внутренние/внешние тени |
| Текст | семейство шрифта; размер; вес; стиль; цвет; line-height; letter-spacing; text-align; переносы |
| Иконки | исходный файл/вектор; размер; viewBox; цвет; толщина штриха; отступы; выравнивание |
| Вариометр | число сегментов; размер сегмента; расстояния; радиусы; цвета каждой зоны; подписи и шкала |
| Время/дата | размеры шрифта отдельно; веса; межстрочный интервал; позиция; разделитель |
| Кнопки | размеры; радиусы; фон/градиент; рамка; тень; иконка; текст; внутренние отступы; gap |
| Состояния кнопок | обычное, нажатое, фокус, disabled; изменение фона, тени, положения, свечения и контраста |

| Системные эффекты | влияние плотности экрана, браузерного масштабирования и системных шрифтов |

## Как завершать калибровку

1. Открыть оригинал в `Aeroclub-Visual-Compare.html` при масштабе 1:1.
2. Измерить границы каждого элемента по исходным пикселям и внести точные координаты в таблицу компонентов.
3. Снять цвета выборкой из пикселей, отдельно для непрозрачных участков, градиентов, полупрозрачных слоёв и теней.
4. Для шрифтов определить семейство/вес по доступным исходникам; если растр не позволяет установить точное семейство, отметить это явно, а не угадывать.
5. Измерить обычные и нажатые состояния по нижним образцам дизайн-листа.
6. Сверить суммы размеров и отступов, а также взаимное расположение вложенных блоков.
7. Только после заполнения таблиц фактическими значениями считать калибровку завершённой и переходить к HTML/CSS.

## Критерий готовности

Калибровка готова к кодированию только тогда, когда у каждого видимого элемента есть: идентификатор, границы/контейнер, измеренные стили, источник значения, состояние и отметка уверенности. Все неустановимые по растру параметры должны быть помечены как неизвестные/требующие исходного ресурса — не заменять их выдуманными значениями.
