# GPTSenderTest

Отдельный Android-проект для анализа автоматической вставки и отправки текста в поле сообщения ChatGPT.

**Важно:** GPTSenderTest — самостоятельный проект; он не является частью PMCA.
Папка `PMCA/` к этому проекту не относится.

Основные компоненты находятся в `app/src/main/java/com/test/accessibility3/`.
