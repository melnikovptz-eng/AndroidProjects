# PMCA — единый план реорганизации

## Этап A. Сохранение и инвентаризация
- Резервная копия исходников.
- Перечень классов и зависимостей.
- Сборка исходной версии.

## Этап B. Контракт выполнения
- Единый ExecutionContext.
- Уникальный ID операции.
- Единая модель результата.
- Единые состояния выполнения.

## Этап C. Каналы Termux
- Выделить RUN_COMMAND в отдельный адаптер.
- Выделить файловый JSON-мост в отдельный адаптер.
- Сохранить совместимость с существующим контроллером.
- Проверить соответствие operation ID.

## Этап D. Централизованное управление
- Parser.
- DuplicateGuard.
- ProcessingGate.
- ExecutionQueue.
- ModuleRegistry.
- ModuleRouter.
- ResultManager.
- StateManager.

## Этап E. Интерфейс и диагностика
- MainActivity.
- FloatingPanelService.
- Clipboard.
- Logger.
- HealthChecker.

## Этап F. Тестирование
- Чистая сборка.
- Проверка запуска команды.
- Проверка stdout/stderr/exit code.
- Проверка устаревшего результата.
- Проверка повторной команды.
- Проверка JSON-моста.
- Проверка плавающей панели.
- Установка APK и итоговая проверка.

Ни один этап не считается успешным без проверки результата.
