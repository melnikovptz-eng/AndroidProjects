# PMCA — СПЕЦИФИКАЦИЯ АВТОКОПИРОВАНИЯ

## Цель

После каждого значимого этапа результат должен автоматически становиться
доступным для вставки в чат без ручного выделения и Ctrl+C.

## Целевой поток

1. Входные данные получены.
2. Контроллер регистрирует операцию.
3. Модуль выполняет обработку.
4. Результат передаётся контроллеру.
5. Logger фиксирует итог.
6. Контроллер передаёт текст в ClipboardCopyModule.
7. Модуль возвращает статус копирования.
8. Пользователь может вставить результат.

## Единственный исполнитель

ClipboardCopyModule должен быть единственным актуальным исполнителем
операции копирования в рамках PMCA.

Нельзя оставлять несколько параллельных модулей, копирующих один и тот
же результат независимо друг от друга.

До интеграции этого модуля существующий Termux-мост продолжает выполнять
свою известную функцию. Нельзя считать будущий модуль подключённым,
пока это не подтверждено.

## Termux-мост: зафиксированное поведение

Известный вызов:
timeout 3s termux-clipboard-set

Копирование должно:
- завершаться по тайм-ауту;
- не блокировать весь процесс навсегда;
- регистрировать успех или ошибку;
- не запускать повторные демоны;
- не уничтожать исходный буфер до чтения команды CLIPBOARD_GET.

Для CLIPBOARD_GET нельзя предварительно копировать входные данные
в буфер: сначала нужно прочитать существующее содержимое.

## Ошибки

При ошибке копирования:
- записать её в лог;
- вернуть контроллеру статус ошибки;
- не делать бесконечных повторов;
- не переключаться скрытно на старую реализацию;
- сохранить сам результат, если это возможно.

## Целостность текста

Нужно сохранять полный текст, включая переводы строк и маркеры.
Не добавлять лишние символы в полезную нагрузку.
Служебные префиксы разрешены только там, где они предусмотрены
контрактом соответствующего канала.

## Проверка при реальной интеграции

Проверить только:
- вызов нового модуля контроллером;
- успешное копирование результата;
- поведение при недоступном clipboard API;
- отсутствие параллельного старого исполнителя.

Повторные стресс-тесты размеров не являются обязательным этапом,
если нет реального симптома обрезания.

## Текущее ограничение

На дату создания паспорта единый ClipboardCopyModule ещё не подтверждён
как подключённый компонент Android-приложения.
Нельзя выдавать спецификацию за готовую реализацию.
