# PMCA — ЖУРНАЛ АРХИТЕКТУРНЫХ РЕШЕНИЙ

## ADR-001 — Единственный актуальный модуль

Решение: для каждой функции работает только последняя утверждённая
реализация.

Старая реализация не запускается параллельно и не используется
как скрытый резервный путь.

При ошибке новая реализация должна вернуть ошибку и записать её в лог.

## ADR-002 — Центральный контроллер

Решение: центральный контроллер управляет последовательностью обработки.
Модули не должны независимо управлять всей системой.

## ADR-003 — Единый модуль копирования

Решение: автокопирование должно быть вынесено в единый
ClipboardCopyModule и вызываться через установленный центральный путь.

До фактической интеграции работающий Termux-мост не удалять.

## ADR-004 — Без бесконечного исследования

Решение: использовать паспорт и журнал состояния как исходную точку.
Повторные проверки делать только для конкретной задачи или ошибки.

## ADR-005 — Ограниченный clipboard-вызов

Решение: вызов termux-clipboard-set ограничивается тайм-аутом.
Сбой буфера не должен навсегда блокировать обработку.

## ADR-006 — Безопасность рабочих файлов

Решение: перед изменениями рабочего кода сохранять резервную копию.
Не удалять очереди, результаты и старые проекты без необходимости.

## ADR-007 — Терминальная передача результата

Решение: по умолчанию скрипты должны копировать полный полезный отчёт
в буфер обмена, если это возможно, и завершаться понятным маркером.

## ADR-008 — Кнопки 1C, 2C, 3C

Зафиксировано: 1C должна копировать весь вывод предыдущей команды
от начала её вывода до конца, без повторного выполнения команды.

Точное назначение 2C и 3C не закреплено в доступных записях.
Не придумывать их назначение без подтверждения.
