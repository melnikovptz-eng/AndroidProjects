# PMCA — главная инструкция проекта

PMCA = Portable Modular Controller Architecture.

## С чего начинать

Перед любыми изменениями изучить документы в следующем порядке:

1. PROJECT_PASSPORT.md
2. CURRENT_STATE.md
3. PROJECT_CONTRACT.md
4. ARCHITECTURE.md
5. MODULE_REGISTRY.md
6. CLIPBOARD_AUTOCOPY_SPEC.md
7. DECISIONS.md
8. HANDOFF.md

При восстановлении после сбоя дополнительно читать RECOVERY.md.

## Обязательные правила

- Для каждой функции существует один актуальный исполнитель.
- Центральный контроллер управляет последовательностью обработки.
- Модули не дублируют ответственность друг друга.
- Новая реализация не работает параллельно со старой реализацией той же функции.
- Старую реализацию нельзя незаметно использовать как резервный путь.
- Ошибки фиксируются в журнале.
- Перед изменением существующего рабочего кода сохраняется резервная копия.
- Нельзя удалять пользовательские данные, очереди и результаты без необходимости.
- Нельзя запускать дополнительные экземпляры демона без обоснованной необходимости.
- Автокопирование результата должно работать на всём пути обработки.
