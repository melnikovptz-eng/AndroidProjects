# Обязательный стандарт: реестр задач и карта экранов

Применяется ко всем проектам репозитория и будущим проектам.

- Каждый проект обязан иметь `TASK_REGISTRY.md` и `SCREEN_MAP.md`.
- До начала работ ИИ читает реестр задач, карту экранов и рабочий журнал, проверяет актуальную ветку/HEAD и продолжает с первой незакрытой задачи с наивысшим приоритетом.
- Новые пользовательские дефекты сначала фиксируются в реестре; блокирующие задачи ставятся сверху.
- Каждая задача имеет постоянный ID, приоритет, статус, точное описание, критерии приёмки и данные о проверке.
- Каждый экран/значимое состояние получает постоянный ID. Виджеты имеют отдельный префикс (например W01). ID не переиспользовать.
- Отчёты и коммиты должны ссылаться на ID задачи и экрана. Закрытые задачи не удалять.
- Сборка CI, unit-тесты, соответствие APK текущему SHA и тест на физическом устройстве — разные статусы.
