# VoiceActivation-Next

Экспериментальная Android-система для измерения микрофонного сигнала, калибровки обнаружения речи и проверки активационной команды через локальный Vosk.

См. [паспорт](docs/PASSPORT.md) и [техническое задание](docs/TECHNICAL_SPECIFICATION.md).

**Разработка:** с нуля, строго модуль за модулем. Следующий модуль не начинается до реализации и тестирования предыдущего. APK будет объявлен готовым только после полной интеграции и контрольных испытаний.

Текущий этап: **01 — AudioCapture**.
