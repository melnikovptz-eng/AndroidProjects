# Voice Activation Next — порядок калибровки

Версия приложения: 1.9.0 (versionCode 10)  
Ветка: voice-activation-rebuild

## 1. Подготовить профиль владельца и команды

1. Откройте приложение и разрешите доступ к микрофону.
2. Нажмите «Записать профиль владельца». Говорите обычным голосом до окончания записи (2,5 секунды). Повторная запись профиля заменяет предыдущий профиль.
3. В поле «Название команды» введите короткое имя, например СТАРТ.
4. Нажмите «Записать образец команды» и произнесите эту команду.
5. Повторите запись не менее пяти раз для каждой команды. Меняйте обычную громкость и интонацию. Хранится до шести последних образцов на команду.

## 2. Откалибровать обнаружение речи (VAD)

Нужны отдельные записи, чтобы приложение могло подобрать пороги RMS/PEAK и временные параметры.

1. Нажмите «VAD: записать фоновый шум (4 секунды)». В течение четырёх секунд молчите. Сделайте это минимум два раза.
2. Нажмите «VAD: записать речь (4 секунды)». За четыре секунды произнесите несколько коротких фраз, оставляя обычные паузы между ними. Сделайте это минимум два раза.
3. Нажмите «Показать данные калибровки VAD» и проверьте количество сессий.
4. Нажмите «VAD: подобрать пороги по записям».

Приложение подбирает RMS- и PEAK-пороги на предыдущих сессиях, а последние отдельные записи шума и речи использует для независимой проверки. По временным промежуткам речевых сессий оцениваются пауза окончания фразы, минимальная и максимальная длительность. При неудачной проверке новые коэффициенты не применяются.

## 3. Собрать данные для распознавания команды и голоса владельца

Сначала профиль владельца и образцы команд должны быть записаны.

1. Введите имя уже существующей команды в поле «Название команды».
2. Нажмите «Калибровка: записать правильную команду». Произнесите именно выбранную команду своим голосом. Нужно минимум десять таких примеров суммарно и не менее пяти для каждой команды.
3. Нажмите «Калибровка: записать постороннюю фразу своим голосом». Произнесите фразу, которой нет среди зарегистрированных команд. Нужно минимум десять примеров.
4. Попросите другого человека произнести несколько фраз и нажмите «Калибровка: записать чужой голос». Нужно минимум десять примеров.
5. Нажмите «Показать данные калибровки». Сводка показывает общий счёт и количество примеров по каждой команде.
6. Нажмите «Рассчитать и проверить пороги».

Расчёт подбирает порог DTW, относительный отрыв best/second и порог MFCC cosine владельца. Последние примеры каждого класса остаются для независимой проверки. Если проверка не проходит, пороги не сохраняются: добавьте новые разнообразные и правильно размеченные записи.

## 4. Проверить результат

- «Проверить голосовую команду» — 15-секундная проверка. Каждая фраза анализируется после паузы; результаты и счётчики появляются по ходу теста.
- «Боевой режим — начать» — непрерывное прослушивание до ручной остановки. Произносите команды и посторонние фразы по очереди, разделяя их паузами. Результат каждой фразы выводится сразу.
- «Показать журнал боевого режима» — открыть сохранённые результаты.
- «Показать параметры обнаружения речи» — посмотреть действующие пороги и временные коэффициенты.

## Что именно сохраняется

Сырые аудиозаписи не сохраняются. Локально хранятся MFCC-шаблоны команд, MFCC-профиль владельца, численные метрики и метки калибровочных примеров, а также RMS/PEAK-значения калибровочных VAD-кадров. Эти показатели предназначены для экспериментального подбора коэффициентов и не являются гарантией биометрической идентификации.
