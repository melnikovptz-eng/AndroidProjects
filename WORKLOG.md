- **Подтверждённые изменения в исходниках по истории текущей ветки:**
  - локальное JSON-хранилище с миграцией старых SharedPreferences, атомарной записью и последовательной асинхронной записью;

  - состояние запроса разрешения уведомлений перенесено в локальное хранилище;
  - серверный outbox заменён совместимым локальным no-op фасадом, серверный режим не включён;
  - обработчик напоминаний повторно проверяет существование/актуальность вылета перед уведомлением;
  - удаление связанных demo-данных выполняется после успешного сохранения вылета;
  - ответ участника проверяет существование вылета и подтверждает результат записи;
  - прокрутка информера улучшена для небольших экранов; принудительный звук нажатия не добавляется;
  - исправлено сохранение года даты при редактировании вылета;
  - исправлен вывод локального объявления (перенос строки); метаданные файла и чтение JSON в MSG-02 выполняются в фоновом потоке, циклы проверок не накладываются;
  - добавлены граничные unit-тесты дат/времени, а также тесты общей валидации названия вылета и имени участника;
  - из APK удалено встраивание GitHub-токена и сетевые разрешения, которые использовались только для отладочной отправки; журнал остаётся локальным, передаётся только по явному действию пользователя через системное меню «Поделиться»;
  - workflow запускает доступные unit-тесты всех Gradle-модулей и собирает APK при изменениях исходников/ресурсов/сборки; Markdown-only commits больше не запускают лишнюю сборку;
  - исправлено расписание напоминаний: после создания/редактирования вылета расписание сразу пересчитывается, при удалении alarm отменяется; после перезагрузки и изменения даты/времени/часового пояса расписание восстанавливается.
